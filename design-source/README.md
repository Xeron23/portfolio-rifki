# NODE / 01 — custom backend study

A locally modeled, physically lit API → compute → database system architecture study created specifically for this portfolio. No generated images or stock 3D assets.

- `backend-study.blend`: editable Blender 4.3.2 scene, hero camera and softbox rig.
- `backend-study.py`: reproducible scene builder and two-shot renderer. Run from any directory with `blender -b --python /absolute/path/backend-study.py`.
- `../public/studio3d/backend-node.glb`: object-only glTF export with bevels applied; no camera, lights or cyclorama. Z-up source is converted to glTF Y-up by Blender. Approximate dimensions 4.95 × 2.5 × 1.6 model units, resting near Z=0. Orbit target should be at height 0.7 or use automatic bounds centering. The GLB is 2.2 MB and contains separate named components including data packet lights, allowing restrained client-side animation.
- `../public/studio3d/backend-hero.webp`: 1200 × 1400 hero photography.
- `../public/studio3d/backend-hero-wide.webp`: 1200 × 1000 cropped hero variant with less vertical whitespace.
- `../public/studio3d/backend-detail.webp`: 1400 × 1000 alternate elevated view.

Materials: warm alloy, terracotta anodized aluminum, graphite structural alloy, olive ceramic circuit substrate, machined steel and amber emitters. The lid vents are actual open spaces between modeled metal bridges. Other physical details include connector contacts, finned heat sink, memory packages, bus strips, fasteners and feet. Front-facing ports determine the preferred orbit angle.

Cycles CPU, 96 samples, physically soft area lighting, AgX. The installed Blender build lacks OpenImageDenoise, so the source disables denoising for reproducibility. PNG render masters can be regenerated by the script; WebP delivery uses Pillow quality 88 / method 6.

The current architecture includes an API gateway slab, exploded compute node, three-layer cylindrical database and two physical terracotta data paths. Both final renders were inspected visually. Render masters are kept under design-source, out of public payloads.
